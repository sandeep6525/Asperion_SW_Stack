## 🌟 Executive Summary

The **Asperion Enterprise Operating System** is a unified, end-to-end full-stack software stack engineered from Asperion's operational packs, spreadsheets, legal manuals, and statutory guidelines. It digitizes corporate governance, sales deal desk, financial accounting, statutory payroll, agile project delivery, vendor sourcing, cloud infrastructure, and cybersecurity war-room operations.

## 🛠️ Quickstart Guide

### 1. Requirements
- Python 3.10+ (Verified on Python 3.14.3)
- Dependencies installed via `pip install -r requirements.txt`

### 2. Launch the Web Application
Run the local web server:
```powershell
python run_server.py
```
Open your browser to:
- **Interactive Web Dashboard**: [http://127.0.0.1:8080](http://127.0.0.1:8080)
- **Interactive OpenAPI Documentation**: [http://127.0.0.1:8080/docs](http://127.0.0.1:8080/docs)
- **ReDoc API Reference**: [http://127.0.0.1:8080/redoc](http://127.0.0.1:8080/redoc)

### 3. Run Automated Tests
Execute the 113 automated unit and integration tests (100% passing across 19 test suites):
```powershell
python -m pytest -c pytest.ini tests -v
```
